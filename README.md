# 南极科考站图鉴

一份中文图文指南，介绍南极洲的代表性科考站，以及科学家如何通过冰川、海洋和大气研究了解地球。

**网站地址：** [打开南极科考站图鉴](https://marlonsze-hox.github.io/Antarctic-research-station/)

## 网站内容

- **罗瑟拉站（Rothera）**：位于阿德莱德岛，支持海洋生物、冰川和气候等研究。
- **麦克默多站（McMurdo）**：位于罗斯岛，是美国南极计划的重要后勤枢纽。
- **阿蒙森—斯科特站（Amundsen–Scott）**：位于地理南极点附近，支持极地科学研究和长期观测。

页面同时提供研究机构的一手资料链接和图片署名。

## 本地查看

下载仓库后，用浏览器打开根目录下的 `index.html` 即可。网页图片通过网络加载，因此查看图片时需要连接互联网。
